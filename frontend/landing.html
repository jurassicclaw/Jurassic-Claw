BUILT FOR BUILDERS

🦕
Live Paddock
Each AI agent appears as an animated dinosaur. Speed reflects workload, color reflects status. Watch your agents roam in real-time.
⚡
Real-time WebSocket
Every log line, tool call, and status change streams instantly to your dashboard via WebSocket. Zero polling, zero lag.
🔒
BYOK — Your Keys
Bring Your Own API Key. Stored in localStorage only, never persisted on server. 100% private. We never see your key.
💬
Direct Chat
Chat directly with any running agent. Ask it what it's working on, redirect it, or give feedback — all in real-time.
📂
Files Tab
View and download any file your agents create in the workspace. Research reports, code, data — all accessible instantly.
🔌
OpenClaw Protocol
Connect external agents (LangChain, CrewAI, custom) to the paddock. Any agent with a /status endpoint gets its own dino.
📱
Telegram Notifications
Get notified on agent spawn, completion, error, and OpenClaw discovery. Your dinos report to your phone.
🆓
Free & Open Source
MIT license. Full codebase on GitHub. No subscription, no credit card, no telemetry. Deploy your own or use ours.
